Drill 6 — Why naive Fibonacci is exponential but DP is linear

Recursive Fib computes $F_3$ twice, $F_2$ three times, leading to $T(n)=\Theta(\varphi^n)$. Memoized Fib stores each $F_k$ once → $\Theta(n)$. Same idea generalises: DP saves you from re-solving overlapping sub-problems.

Drill 7 — TSP (n=4 example)

Cities 1–4 with distance matrix; using Held–Karp DP we enumerate $2^4=16$ subsets times 4 ends. Total $\Theta(4^2\cdot 2^4) = 256$ table cells — explains why DP TSP works for $n\le 20$ but not $n=100$.

Drill 8 — Top-down vs Bottom-up code skeleton (Knapsack)

Memoization: function solve(i, w): if i = 0 or w = 0: return 0 if memo[i][w] != −1: return memo[i][w] ... Tabulation: for i = 1..n: for w = 0..W: K[i][w] = ...
Both are $\Theta(nW)$; tabulation has smaller constants in tight loops.
