⚡ Unit 5 — Quick Revision

DP applicability

Optimal substructure + Overlapping sub-problems ⟹ DP.

Memoization vs Tabulation

Same asymptotic cost. Memo = top-down recursion + cache. Tab = bottom-up table fill.

Greedy vs DP — picking the right tool

Greedy when greedy-choice property holds (Fractional Knapsack). DP otherwise (0/1 Knapsack, MCM, TSP).

Common DP signatures

• 2-D table indexed by (i, j) where i,j are positions → $\Theta(n^2)$.
• 2-D table indexed by (item, capacity) → $\Theta(nW)$ pseudo-polynomial.
• 3-D table (subset, end-vertex, length) → exponential.
