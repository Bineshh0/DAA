RAM model

Every primitive op (arith, compare, assign, index, call) = $O(1)$. Random memory access. No cache/parallelism. Time = count of primitive ops.

Best / Worst / Average

Best = $\Omega$ floor · Worst = $O$ ceiling (used for guarantees) · Average = $\Theta$ over input distribution.

Factorial

Iterative: $T=\Theta(n)$, $S=\Theta(1)$. Recursive: $T=\Theta(n)$, $S=\Theta(n)$ stack.

Aggregate analysis

Sequence cost / n = amortized. Binary counter increments: total $<2n$ flips ⟹ $O(1)$ amortized.

Recurrence cheat-sheet

T(n)=T(n/2)+1 → $\Theta(\log n)$ — Binary Search
T(n)=2T(n/2)+1 → $\Theta(n)$ — tree traversal
T(n)=2T(n/2)+n → $\Theta(n\log n)$ — Merge Sort
T(n)=T(n-1)+1 → $\Theta(n)$
T(n)=T(n-1)+n → $\Theta(n^2)$ — Quick Sort worst
T(n)=2T(n-1)+1 → $\Theta(2^n)$ — Tower of Hanoi

How to pick a method

Fits $aT(n/b)+f(n)$ → Master first. Subtract-recurrence or gap case → Recursion tree. Need rigorous proof of a guessed bound → Substitution.
