Little-o & Little-ω (strict bounds)

$o(g)$: $\lim_{n\to\infty} f/g = 0$ — strictly smaller. e.g. $n = o(n^2)$.
$\omega(g)$: $\lim_{n\to\infty} f/g = \infty$ — strictly larger. e.g. $n^2 = \omega(n)$.
Equivalence: $f=\Theta(g) \iff f=O(g)\,\text{AND}\,f=\Omega(g)$.

When Master Theorem fails — gap cases

Whenever $f(n)$ is larger/smaller than $n^{\log_b a}$ but not polynomially so (i.e. no $\epsilon>0$ works), Master Theorem is silent. Example: $T(n)=2T(n/2)+n\log n$ → tree gives $\Theta(n\log^2 n)$. General fix: Akra–Bazzi.

Akra–Bazzi method (mini)

For $T(n)=\sum_i a_i T(n/b_i)+g(n)$, find $p$ with $\sum a_i b_i^{-p}=1$. Then $T(n)=\Theta\big(n^p\big(1+\int_1^n g(u)/u^{p+1}du\big)\big)$. Handles unequal splits and non-polynomial $g(n)$.

Other amortized methods

Accounting: assign each operation an amortized cost, store credits to pay later expensive operations.
Potential: define $\Phi(D)$ on data-structure state; amortized cost = actual cost + $\Delta\Phi$. Used for splay trees, Fibonacci heaps, dynamic tables.

Useful asymptotic identities

$\log(n!) = \Theta(n\log n)$ (Stirling)
$\sum_{i=1}^{n} 1/i = \Theta(\log n)$ (harmonic)
$\sum_{i=0}^{n} r^i = \Theta(r^n)$ if $r>1$, $=\Theta(1)$ if $r<1$
$n! = \Theta(\sqrt{n}(n/e)^n)$

Common pitfalls

• Big-O isn't tight: $n=O(n^{100})$ — true but useless. Use $\Theta$ when possible.
• Inside $\Theta$/$O$ the base of $\log$ is irrelevant (constant factor).
• "Worst case" ≠ Big-O; worst case is a function, Big-O is a bound on a function. We often have "worst case is $\Theta(n^2)$ which is $O(n^2)$."
• Recursive algorithms have two complexities — time AND stack space; don't forget the second.

Viva quick-fire

Q: Why drop constants? A: They depend on machine; growth rate is what matters as $n\to\infty$.
Q: Why is worst case preferred? A: It is a hard guarantee; average case requires assuming an input distribution.
Q: RAM vs Turing machine? A: RAM has $O(1)$ random access; Turing tape access is sequential, so analyses can differ by polynomial factors.
Q: Can $\Theta(g)$ exist if $O(g) \ne \Omega(g)$? A: No, $\Theta$ requires both bounds with the same $g$.
Q: Is $2^{n+1}=O(2^n)$? A: Yes — constant factor 2.
Q: Is $2^{2n}=O(2^n)$? A: No — ratio $2^n$ is unbounded.
