🎯 Unit 1 — Topic-wise Practice Drill

Use these worked examples to internalise every syllabus topic. They naturally cover every board / model question pattern.

Drill 1 — Deriving $T(n)$ from pseudocode

Given the nested-loop snippet:
for i = 1 to n: for j = 1 to i: x = x + 1
Counting primitive operations: inner loop runs $i$ times for each outer $i$. Total $= \sum_{i=1}^{n} i = n(n+1)/2 = \Theta(n^2)$. This pattern (summation of arithmetic series) is the standard way exam questions test the RAM model.

Drill 2 — Proving a function is $O$, $\Omega$, $\Theta$

Show $f(n)=3n^2+5n+7 = \Theta(n^2)$.

Upper: for $n\ge 1$, $3n^2+5n+7 \le 3n^2+5n^2+7n^2 = 15n^2$. Choose $c_2=15,n_0=1$ → $O(n^2)$.
Lower: $3n^2+5n+7 \ge 3n^2$. Choose $c_1=3$ → $\Omega(n^2)$.
Both hold ⟹ $\Theta(n^2)$.

Drill 3 — Aggregate analysis (binary counter)

k-bit counter incremented $n$ times. Bit $i$ flips $\lfloor n/2^i\rfloor$ times. Total flips $\le n\sum_{i\ge 0} 1/2^i = 2n$. Hence amortized cost per increment $= 2n/n = O(1)$ even though a single increment can cost up to $O(\log n)$.

Drill 4 — Substitution method

Prove $T(n)=2T(n/2)+1$ is $O(n)$.
Guess T(n) ≤ cn − 1 Base T(1)=1 ≤ c−1 ⟹ c ≥ 2 ✓ IH T(n/2) ≤ c(n/2)−1 Step T(n) = 2T(n/2)+1 ≤ 2[c(n/2)−1]+1 = cn − 1 ✓ ∴ T(n)=O(n)

Drill 5 — Recursion-tree method

Solve $T(n)=2T(n/2)+n$.
Level k: 2^k nodes, each of size n/2^k, cost per node n/2^k Level cost = 2^k · n/2^k = n (constant per level) Depth = log₂ n Total = n · log n = Θ(n log n)

Drill 6 — Master Theorem (10 patterns)

① 2T(n/2)+n → Case 2 → Θ(n log n) ② 2T(n/2)+n² → Case 3 → Θ(n²) ③ 2T(n/2)+1 → Case 1 → Θ(n) ④ 3T(n/2)+n → Case 1 → Θ(n^{log₂3}) ⑤ 2T(n/4)+√n → Case 2 → Θ(√n log n) ⑥ 4T(n/4)+n → Case 2 → Θ(n log n) ⑦ 7T(n/2)+n² → Case 1 → Θ(n^{log₂7}) ⑧ 9T(n/3)+n → Case 1 → Θ(n²) ⑨ 2T(n/4)+n² → Case 3 → Θ(n²) ⑩ 5T(n/4)+kn → Case 1 → Θ(n^{log₄5})
For every one: identify $a$,$b$,$f(n)$; compute $n^{\log_b a}$; compare; pick case; write answer.

Drill 7 — When Master fails

$T(n)=2T(n/2)+n\log n$. Here $n^{\log_2 2}=n$ and $f=n\log n$ is larger than $n$ but not polynomially larger ⟹ Case 3 fails. Use recursion tree: each level still costs $n\log(n/2^k)$, summing gives $\Theta(n\log^2 n)$.

Drill 8 — Geometric interpretation

Sketch $f(n)$ together with $c\,g(n)$. For $O$: the line $c\,g(n)$ stays above $f$ after some $n_0$. For $\Omega$: stays below. For $\Theta$: two lines sandwich $f$. This is the figure examiners draw for Big-O / Big-Ω / Big-Θ.

Drill 9 — Recursive vs iterative space

Factorial: iterative uses $\Theta(1)$ memory; recursive uses $\Theta(n)$ because each call pushes a stack frame. Always mention this distinction in space-complexity answers.
