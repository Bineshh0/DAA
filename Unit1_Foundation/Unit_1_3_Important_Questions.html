🎯 Unit 1 — Important Questions (Model + Boards)

Q1. [Model 10M / Board 2078] Need of algorithm analysis + RAM model + Big-O,Ω,Θ with examples

Need: compare algorithms, predict resource use, prove correctness, choose best for input size — independent of language/hardware.

RAM Model: theoretical machine; every primitive op (arithmetic, compare, assign, array index, call/return) = $O(1)$; memory random-access; no cache or parallelism.

Big-O: $f(n)\le c\cdot g(n)$ ⟹ upper bound. e.g. $3n+5=O(n)$.
Big-Ω: $f(n)\ge c\cdot g(n)$ ⟹ lower bound. e.g. $3n+5=\Omega(n)$.
Big-Θ: both ⟹ tight bound. $3n+5=\Theta(n)$.

Q2. [Board 2080] Iterative factorial + detailed analysis

Factorial(n): fact ← 1 // c1, 1 time for i = 1 to n: // c2, n+1 times fact ← fact * i // c3, n times return fact // c4, 1 time
$T(n)=c_1+c_2(n+1)+c_3 n+c_4 = \Theta(n)$. Space $=\Theta(1)$.

Q3. [Model Q5 / Board 2081 Q5] Master Method

(a) T(n)=3T(n/2)+n: $n^{\log_2 3}\approx n^{1.58}$; $f=n$ is smaller ⟹ Case 1 ⟹ $\Theta(n^{\log_2 3})$.
(b) T(n)=2T(n/4)+\sqrt{n}: $n^{\log_4 2}=n^{0.5}=\sqrt n=f$ ⟹ Case 2 ⟹ $\Theta(\sqrt n\log n)$.
(c) Board 2081(a) T(n)=2T(n/2)+n² ⟹ Case 3 ⟹ $\Theta(n^2)$.
(d) Board 2081(b) T(n)=2T(n/2)+1 ⟹ Case 1 ⟹ $\Theta(n)$.
(e) Board 2076(a) T(n)=7T(n/2)+n²: $n^{\log_2 7}\approx n^{2.81}$ ⟹ Case 1 ⟹ $\Theta(n^{\log_2 7})$.
(f) Board 2076(b) T(n)=4T(n/4)+n: $n^1=f$ ⟹ Case 2 ⟹ $\Theta(n\log n)$.

Q4. [Board 2080 Q1] T(n)=2T(n/2)+1 by Substitution → O(n)

Guess: T(n) ≤ cn − 1 Base: T(1)=1 ≤ c−1 ⟹ c≥2 IH: T(n/2) ≤ c(n/2) − 1 Step: T(n) = 2T(n/2)+1 ≤ 2[c(n/2)−1]+1 = cn−1 ✓ ∴ T(n) = O(n)

Q5. [Board 2078 Q4] Recursion-tree method for T(n)=2T(n/2)+1

Level nodes cost/node level cost 0 1 1 1 1 2 1 2 2 4 1 4 … k 2^k 1 2^k Depth = log₂n; leaves = n Total = 1+2+…+n = 2n−1 = O(n)

Q6. [Board 2080 Q12a] Aggregate Analysis

Total cost of n ops divided by n gives amortized cost. Example: binary counter — incrementing from 0 to n flips $\sum n/2^k < 2n$ bits ⟹ $O(1)$ amortized per increment.

Q7. [Board 2079 Q8a] Best, Worst, Average case

Best ($\Omega$): least operations (Linear Search → $O(1)$).
Worst ($O$): max operations — gives guarantee ($O(n)$).
Average ($\Theta$): expected over input distribution ($O(n/2)$).
