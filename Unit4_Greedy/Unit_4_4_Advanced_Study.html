🧪 Unit 4 — Tricky Variations & Common Mistakes

1. Fractional vs 0/1 Knapsack — the classic trap

Examiners love to give a 0/1 knapsack problem and watch students apply ratio-greedy. If items are indivisible, greedy is NOT optimal — use DP (Unit 5). Always check the problem wording first.

2. Job Sequencing — picking the LATEST free slot

A common bug: placing a job in the earliest free slot. That wastes late slots for jobs that have larger deadlines. Rule: for each job, scan from min(D, deadline) down to 1; first empty slot wins.

3. Kruskal vs Prim — which to choose?

Both produce MSTs of the same total weight (MST may not be unique, but its weight is). Use Kruskal when graph is sparse (edge list given). Use Prim when graph is dense (adjacency matrix given) — the $O(V^2)$ array implementation can beat $O(E\log V)$.

4. Dijkstra and negative edges

Even a single negative edge can produce wrong answers because Dijkstra commits to the first finalised distance. Use Bellman–Ford ($O(VE)$) for negatives, or Johnson’s algorithm for all-pairs.

5. Re-insertion of relaxed vertices

Pseudocode often uses ExtractMin / DecreaseKey. In implementations without DecreaseKey (e.g. std::priority_queue in C++), one usually re-inserts a vertex with the smaller key and ignores stale entries when popped. Complexity stays $O(E\log V)$.

6. Huffman — tie-breaking

When two nodes share a frequency, the choice can change the tree shape (and individual code lengths) but never the total bit count — every valid Huffman tree achieves the optimum sum. So examiners can’t mark you wrong for picking either order, as long as the merge step is correct.

7. Prefix code property

Why prefix codes? Because the receiver decodes left-to-right without delimiters. If 10 is a code, 1010 cannot also be one — else “1010” would be ambiguous.

8. Optimal substructure check

Before applying greedy, prove (informally OK) that an optimal solution remains optimal when you remove the first greedy choice. If it doesn’t, greedy fails (e.g. “make change” with coin set {1,3,4} for amount 6 — greedy gives 4+1+1, optimum is 3+3).

9. Complexity confusion

$O(E\log V) = O(E\log E)$ because $E \le V^2 \Rightarrow \log E \le 2\log V$. Either notation is acceptable in exams.

10. Greedy proofs in 2 lines

Fractional Knapsack: swap any fraction of a lower-ratio item for a higher-ratio item → value cannot decrease.
Huffman: two least-frequent symbols can always be siblings at the deepest level (exchange argument).
Kruskal / Prim: cut property — the lightest edge crossing any cut belongs to some MST.
