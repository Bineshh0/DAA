⚡ Unit 2 — Quick Revision

GCD (Euclid)

while b≠0: a,b ← b, a mod b; return a
$T=O(\log\min(a,b))$, $S=O(1)$. Worst case: consecutive Fibonacci numbers.

Fibonacci

Naive recursive: $T=\Theta(\varphi^n)$, $S=\Theta(n)$.
Iterative: $T=\Theta(n)$, $S=\Theta(1)$ — keep 3 variables.

Sequential Search

Best $\Omega(1)$, Worst $O(n)$, Avg $\Theta(n)$, Space $O(1)$. Works on unsorted data.

Choose which sort?

• Nearly sorted → Insertion (adaptive $\Theta(n+d)$).
• Writes are expensive → Selection (only $n-1$ swaps).
• Teaching/early termination → Bubble (with swapped flag).

Key derivation shortcuts

Sum $1+2+\dots+(n-1) = n(n-1)/2 = \Theta(n^2)$ — backbone of all three sorts.
Linear loop = $\Theta(n)$; nested loop with full inner pass = $\Theta(n^2)$.
