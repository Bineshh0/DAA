Sorting Algorithms : Bubble Sort
BubbleSort(A, n)
{
for(i = 0; i <n-1; i++)
{
for(j = 0; j < n-i-1; j++)
{
if(A[j] > A[j+1])
{
temp = A[j];
A[j] = A[j+1];
A[j+1] = temp;
}
}
}
}
6
Time Complexity:
Inner loop executes for (n-1) times when i=0, (n-2) times 
when i=1 and so on: 
Time complexity 
= (n-1) + (n-2) + (n-3) + …………………………. +2 +1    
= O(n2) 
 
There is no best-case linear time complexity for this 
algorithm.
Space Complexity:
Since no extra space besides 3 variables is needed for 
sorting
Space complexity = O(n)

Sorting Algorithm : Selection Sort
SelectionSort(A)
{
for( i = 0;i < n ;i++)
     {
 
min_idx=i;
          {
 
for ( j = i + 1;j < n ;j++)
 
     if (A[j] < A[min_idx])
                      min_idx=j;
 
 
 
 
 
 
 
 
 
 
             } 
 
 
 
 
 
               swap(A[i],A[min_idx]);
      }
}

    = O(n2)
