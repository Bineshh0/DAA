🎯 Unit 2 — Topic-wise Practice Drill

Drill 1 — Trace GCD(252, 105)

252 mod 105 = 42 → (105, 42) 105 mod 42 = 21 → (42, 21) 42 mod 21 = 0 → (21, 0) result = 21
Only 3 iterations — demonstrates the $O(\log\min(a,b))$ bound.

Drill 2 — Why naive Fibonacci is exponential

Recurrence: $T(n)=T(n-1)+T(n-2)+1$. The number of leaves of the recursion tree equals $F_n$, and $F_n=\Theta(\varphi^n)$ where $\varphi=(1+\sqrt 5)/2\approx 1.618$. The iterative form computes each value once → $\Theta(n)$.

Drill 4 — Sequential Search on $(7,3,9,1,5)$ for key 1

i=0 A[0]=7 ≠ 1 i=1 A[1]=3 ≠ 1 i=2 A[2]=9 ≠ 1 i=3 A[3]=1 = 1 → return 3

Drill 5 — Bubble Sort trace on $(5,1,4,2,8)$

Pass 1 (i=0): (5,1,4,2,8) swap → (1,5,4,2,8) (1,5,4,2,8) swap → (1,4,5,2,8) (1,4,5,2,8) swap → (1,4,2,5,8) (1,4,2,5,8) no → (1,4,2,5,8) Pass 2 (i=1): (1,4,2,5,8) swap → (1,2,4,5,8) rest no swap Pass 3: no swap → break.

Drill 6 — Selection Sort trace on $(29,10,14,37,13)$

i=0 min=10 → (10,29,14,37,13) i=1 min=13 → (10,13,14,37,29) i=2 min=14 → (10,13,14,37,29) i=3 min=29 → (10,13,14,29,37)
Total comparisons $=4+3+2+1=10=n(n-1)/2$.

Drill 8 — Counting cost of nested loops

For each pass $i$ of bubble sort, the inner loop performs $n-1-i$ comparisons. Total $=\sum_{i=0}^{n-2}(n-1-i)=n(n-1)/2 = \Theta(n^2)$. Same series appears in selection & insertion analyses — master this once.

Drill 9 — Stable vs Unstable

Sort the pairs $(3a),(1),(3b),(2)$ by their numeric key. Stable algorithm preserves the original order between $3a$ and $3b$ (bubble/insertion: $1,2,3a,3b$). Selection may swap $3a$ past $3b$ → $1,2,3b,3a$ ⟹ unstable.

Drill 10 — Finding max element (variation of search)

Algorithm Max(A[0..n-1]): m ← A[0] for i = 1 to n-1: if A[i] > m: m ← A[i] return m
$n-1$ comparisons → $\Theta(n)$ time, $\Theta(1)$ space. The optimum number of comparisons to find max alone is $n-1$; finding min AND max together can be done in $\lceil 3n/2 \rceil-2$ comparisons (covered in Unit 3 MinMax).
