2.1 Iterative Searching (Sequential Search)

Sequential Search (Linear Search) evaluates the array strictly elements by element chronologically from index $0$ to $N-1$ until the target value `X` is physically discovered or the array terminates limit bounds.
Algorithm SequentialSearch(A, N, X): 1. for i = 0 to N-1 do 2. if A[i] == X then 3. return i // Element inherently found 4. return -1 // Execution fully exhausted, NOT FOUND

Deriving the Mathematical Time Complexity:

  • Best Case Bound $\Omega(1)$: The target $X$ resides perfectly precisely at $A[0]$. The `if` condition inherently evaluates strictly to TRUE upon the absolute $1st$ execution sequence. The loop aborts safely. Thus, $T(N) = \Omega(1)$.
  • Worst Case Bound $O(N)$: The integer $X$ is mathematically totally missing from the array memory banks, OR strictly placed at the terminal absolute index $A[N-1]$. The loop must universally loop $N$ times natively. Total cost algebraically sums: $T(N) = \sum_{i=1}^{N} c \Rightarrow c \cdot N$. Result definitively matches $O(N)$.

2.2 Sorting: Bubble Sort

Bubble Sort scans the array natively repeatedly, strictly verifying adjacent neighboring memory integers, and forcibly swapping them dynamically if their magnitude is critically out of structured order. Largest integers "bubble" upwards rapidly toward the sequence boundaries continuously.
Algorithm BubbleSort(A, N): 1. for i = 0 to N-2 do 2. for j = 0 to N-i-2 do 3. if A[j] > A[j+1] then 4. SWAP(A[j], A[j+1])

Derivation of the Time Complexity:

Unlike recursive equations requiring Master Method checks, iterative nested boundary limits explicitly require evaluating standard Arithmetic Series mathematical sums:

On the first iteration of $i$, $j$ natively spans from $0$ up to $N-2$, resulting in exactly $N-1$ element comparisons.
On the second structural iteration of $i$, $j$ strictly spans $0$ to $N-3$, yielding $N-2$ comparisons.
This algebraically maps indefinitely until generating exactly $1$ comparison on the terminal $i$ sequence loop. Total Runtime Mathematical $T(N)$ = Total comparisons:
$T(N) = (N-1) + (N-2) + (N-3) + \dots + 2 + 1$
This represents precisely a formal Arithmetic Series sequence: $\sum_{k=1}^{n-1} k$
Using algebraic substitution format equations: $S_n = \frac{n(a_1 + a_n)}{2}$
$T(N) = \frac{(N-1) \cdot (1 + N - 1)}{2} = \frac{N(N-1)}{2}$
Expanding the exact parameters: $T(N) = \frac{1}{2}N^2 - \frac{1}{2}N$

Because asymptotic boundaries natively drop fractional coefficients ($\frac{1}{2}$) and drastically discard subordinate lower powers ($N$), the dominant limit bound executes entirely upon $N^2$.

Bubble Sort Worst/Average Case Time Limit: $T(N) = O(N^2)$

2.3 Sorting: Selection Sort

Selection Sort forcefully isolates the absolute minimum element from the chaotic unsorted array partition explicitly, replacing the very front-most index variable linearly.
Algorithm SelectionSort(A, N): 1. for i = 0 to N-2 do 2. minIndex = i 3. for j = i+1 to N-1 do // Scan specifically searching the absolute minimum 4. if A[j] < A[minIndex] then 5. minIndex = j // Continuously update tracking limit 6. SWAP(A[i], A[minIndex]) // Execute solitary physical memory overwrite swapping action

Derivation of the Time Complexity:

The structural loop execution bounds map almost universally exactly matching Bubble Sort's algebraic boundaries natively. For each index space $i$, the scanning sequence `j` executes explicitly $N - i - 1$ times to confirm the exact physical minimum index target position.

Total Comparisons strictly evaluates mapping:
$T(N) = (N-1) + (N-2) + \dots + 1$
$T(N) = \frac{N(N-1)}{2}$ $T(N) = \frac{N^2}{2} - \frac{N}{2}$
⚠️ Important Property: Unlike all other sorting variants internally, Selection Sort performs precisely EXACTLY $\Theta(N^2)$ sequence evaluations regardless of pre-sorted limits. Best case natively still scans everything to verify $N^2$. However, the physical memory `` array rewriting operations execute strictly at max bounds $O(N)$, which saves physical RAM wear natively.

2.4 Sorting: Insertion Sort

Insertion Sort mimics how humans physically structure decks of playing cards dynamically. The algorithm aggressively identifies a solitary integer index sequentially, extracting it entirely from the target slot, and executes an array limit backward traverse precisely to insert the integer seamlessly into internal mathematical sorted format bounds.
Algorithm InsertionSort(A, N): 1. for j = 1 to N-1 do 2. key = A[j] 3. i = j - 1 4. while i >= 0 AND A[i] > key do // Backward linear tracking 5. A[i+1] = A[i] // Physical array element memory Right Shift 6. i = i - 1 7. A[i+1] = key // Precisely write the target token

Derivation of the Time Complexity constraints:

1. Resolving the BEST Case Limits Configuration:

If the array structure memory strictly initializes already pre-sorted perfectly e.g. $[1, 2, 3, 4, 5]$:

  • The primary line evaluating `A[i] > key` inherently maps strictly executing false immediately universally every `j` sequence!
  • Consequent result: The internal structural `while` loop completely totally systematically aborts every loop, evaluating zero native mathematical shifts.
  • Total algebraic equation sequences trace precisely identically limiting to exactly $N-1$ sequence execution operations strictly.
  • Mathematical Best Case Constraint: $T(N) = \Omega(N)$

2. Resolving the WORST Case Limits Configuration:

If the array fundamentally reverses universally initially e.g. $[9, 8, 7, 6, 5]$, every solitary numeric integer element executes exhaustive shifting recursively backwards universally hitting index $0$.

Iteration j=1: The embedded while loop checks $1$ element natively evaluating true, shifting 1 spot.
Iteration j=2: Loop evaluates $2$ elements sequentially physically.
Iteration j=N-1: Loop completely sequentially executes $N-1$ limit checks.

Algebraic Total Execution Sequences Native = $\Sigma_{j=1}^{N-1} j$
Result = $1 + 2 + 3 + \dots + (N-1)$
Calculated Structural Math Resulting Bound: $\frac{N(N-1)}{2}$

Because the $\frac{N(N-1)}{2}$ executes expanding strictly matching identical polynomial boundaries limiting natively as $O(N^2)$ structure.

Insertion Sort Worst/Average Case Time Limit: $T(N) = O(N^2)$
