⚡ Unit 3 — Quick Revision

D&C template

Divide → Conquer recursively → Combine. Yields $T(n)=aT(n/b)+f(n)$.

Binary Search

$T(n)=T(n/2)+1 = \Theta(\log n)$. Requires sorted array.

MinMax

$T(n)=2T(n/2)+2 = \Theta(n)$. Comparisons $=\lceil 3n/2\rceil-2$ vs naive $2n-2$.

QuickSort worst case

Sorted/reverse-sorted input with last-element pivot → $T(n)=T(n-1)+\Theta(n)=\Theta(n^2)$. Fix: randomize the pivot.

Heap primitives

Parent $=⌊i/2⌋$, Left $=2i$, Right $=2i+1$.
MaxHeapify = $O(\log n)$.
BuildMaxHeap = $O(n)$ (tight, not $n\log n$).
HeapSort = $O(n\log n)$ in-place.

Selection

Randomized: expected $\Theta(n)$, worst $\Theta(n^2)$.
Median-of-Medians (groups of 5): worst-case $\Theta(n)$ — $T(n)\le T(n/5)+T(7n/10)+\Theta(n)$.

Why D&C beats $n^2$

Splitting halves the input → $\log n$ levels of $\Theta(n)$ work = $\Theta(n\log n)$ — matches the comparison-sort lower bound.
