B. Floyd-Warshall Algorithm

⚠️ Note: The specific graph matrix was missing from the text transcript. The following explains the algorithm steps for an arbitrary weighted graph.

Floyd-Warshall is used to find the shortest paths between all pairs of vertices in a weighted graph (even with negative edges, but no negative cycles).

Algorithm:

Let \( D^0 \) be the initial weight matrix of the graph. For \( k = 1 \) to \( n \) (where \( n \) is number of vertices):

\( D^k[i][j] = \min(D^{k-1}[i][j], D^{k-1}[i][k] + D^{k-1}[k][j]) \)

This means: "Is the path from \( i \) to \( j \) shorter if we go through intermediate vertex \( k \)?"

Q210 marks
Quick Sort: Worst Case, Randomized Quick Sort & Trace

A. Worst Case of Quick Sort

The worst-case scenario for standard Quick Sort occurs when the chosen pivot is always the greatest or smallest element. This happens when the array is already sorted (ascending or descending) and the last/first element is picked as the pivot.

Time Complexity drops to O(n²) because the partition heavily unbalances (one sub-array of size \( n-1 \), and one of size 0).

B. Randomized Quick Sort

Instead of picking a fixed pivot (like the last element), Randomized Quick Sort picks a random element from the array and swaps it with the last element before partitioning. This guarantees that the worst-case \( O(n^2) \) behavior depends purely on random chance, making the expected average time complexity consistently O(n log n) regardless of the input data's initial sorting.

Greedy Algorithm & Fractional Knapsack

A. Does Greedy Algorithm guarantee optimal solution?

No, greedy algorithms do not always guarantee an optimal solution for every problem (e.g., they fail on the 0/1 Knapsack problem and Travelling Salesman). A greedy strategy only provides an optimal solution if the problem exhibits Greedy Choice Property (a local optimum leads to a global optimum) and Optimal Substructure (like in Fractional Knapsack or MST).

Master's Method

(a) \( T(n) = 2T(n/2) + n^2 \)

Form: \( T(n) = aT(n/b) + f(n) \). Here \( a = 2, b = 2, f(n) = O(n^2) \).

Compute \( n^{\log_b a} = n^{\log_2 2} = n^1 \).

Since \( f(n) = n^2 \) is polynomially larger than \( n^1 \) (i.e., \( n^2 = \Omega(n^{1+\epsilon}) \) for \( \epsilon=1 \)), we are in Case 3.

Check regularity condition: \( af(n/b) \leq cf(n) \implies 2(n/2)^2 \leq cn^2 \implies \frac{1}{2}n^2 \leq cn^2 \) (True for c=1/2).

Complexity: \( \Theta(n^2) \)

(b) \( T(n) = 2T(n/2) + 1 \)

Here \( a = 2, b = 2, f(n) = O(1) \).

Compute \( n^{\log_b a} = n^{\log_2 2} = n^1 \).

Since \( f(n) = O(1) \) is polynomially smaller than \( n^1 \) (i.e., \( 1 = O(n^{1-\epsilon}) \) for \( \epsilon=1 \)), we are in Case 1.

Complexity: \( \Theta(n) \)

nth Fibonacci Algorithm & Complexity
Algorithm Fibonacci_DP(n)
  if n <= 1 return n
  Let F[0..n] be a new array
  F[0] = 0
  F[1] = 1
  for i = 2 to n
      F[i] = F[i-1] + F[i-2]
  return F[n]
  • Time Complexity: \( O(n) \) — Single loop running n times.
  • Space Complexity: \( O(n) \) — Array of size n (can be optimized to \( O(1) \) using two variables).

Recursion vs Backtracking & Miller-Rabin

Recursion vs Backtracking

Recursion is a programming technique where a function calls itself to solve smaller instances of the same problem. Backtracking is an algorithmic strategy that uses recursion to explore the state-space tree depth-first, but includes a bounding function to stop evaluating paths that cannot possibly lead to a solution (pruning).

Miller-Rabin Randomized Primality Test Complexity

The algorithm performs \( k \) independent iterations to test if a number \( n \) is prime. In each iteration, it does modular exponentiation. Therefore, the time complexity is \( O(k \log^3 n) \). It's highly efficient for very large primes compared to deterministic algorithms.

Chinese Remainder Theorem (CRT)

Equations: \( x \equiv 1 \pmod 3 \), \( x \equiv 2 \pmod 5 \), \( x \equiv 0 \pmod 7 \).

Moduli: \( m_1=3, m_2=5, m_3=7 \). Total \( M = 3 \times 5 \times 7 = 105 \).

\( M_1 = 105/3 = 35 \). Inverse \( y_1 \): \( 35y_1 \equiv 1 \pmod 3 \implies 2y_1 \equiv 1 \pmod 3 \implies y_1 = 2 \)

\( M_2 = 105/5 = 21 \). Inverse \( y_2 \): \( 21y_2 \equiv 1 \pmod 5 \implies 1y_2 \equiv 1 \pmod 5 \implies y_2 = 1 \)

\( M_3 = 105/7 = 15 \). Inverse \( y_3 \): \( 15y_3 \equiv 1 \pmod 7 \implies 1y_3 \equiv 1 \pmod 7 \implies y_3 = 1 \)

Formula: \( x = (a_1 M_1 y_1 + a_2 M_2 y_2 + a_3 M_3 y_3) \pmod M \)

\( x = (1 \cdot 35 \cdot 2 + 2 \cdot 21 \cdot 1 + 0 \cdot 15 \cdot 1) \pmod{105} \)

\( x = (70 + 42 + 0) \pmod{105} = 112 \pmod{105} = 7 \).

x = 7

Approximation Algorithm for Vertex Cover
Vertex Cover: Finding a subset of vertices such that every edge in the graph is incident to at least one vertex in the subset. Finding the minimum cover is NP-Complete.

Approximation Algorithm (Factor 2):

C = empty set
E' = all edges in Graph
while E' is not empty:
   Pick an arbitrary edge (u, v) from E'
   Add both u and v to C
   Remove all edges from E' that are incident to u or v
return C

This greedy strategy guarantees finding a vertex cover that is at most 2 times the size of the optimal minimum vertex cover.

Q115 marks
Cook's Theorem & Problem Reducibility

Cook's Theorem (Cook-Levin Theorem): States that the Boolean Satisfiability Problem (SAT) is NP-Complete. It proves that any problem in NP can be reduced to SAT in polynomial time. If a polynomial time algorithm is found for SAT, it implies P = NP.

Problem Reducibility (\( \propto \)): Problem A is polynomial-time reducible to Problem B (denoted A \( \leq_p \) B) if any instance of A can be transformed into an instance of B in polynomial time, such that the answer to B provides the answer to A. It is used to prove NP-Completeness (e.g., reducing SAT to 3-SAT to Vertex Cover).

Short Notes

(a) Big Oh (O), Big Omega (\( \Omega \)), Big Theta (\( \Theta \))

  • Big Oh (O): Asymptotic upper bound. Represents worst-case complexity. \( f(n) \leq cg(n) \).
  • Big Omega (\( \Omega \)): Asymptotic lower bound. Represents best-case complexity. \( f(n) \geq cg(n) \).
  • Big Theta (\( \Theta \)): Asymptotic tight bound. Represents average/exact complexity. \( c_1g(n) \leq f(n) \leq c_2g(n) \).

(b) Class P, Class NP, and NP-Complete

  • Class P: Problems that can be solved by a deterministic Turing machine in polynomial time. (e.g., Sorting).
  • Class NP: Problems where a given solution can be verified in polynomial time. (e.g., Sudoku, Knapsack).
  • NP-Complete: The hardest problems in NP. A problem is NP-Complete if it is in NP, and every other problem in NP can be reduced to it in polynomial time (e.g., SAT, TSP).
