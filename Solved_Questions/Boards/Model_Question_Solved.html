Question 1: Algorithm Analysis, RAM Model, and Asymptotic Notations (2+3+5)

Why Algorithm Analysis is Needed (2 marks)

  • Performance Prediction: Helps predict how an algorithm will perform with different input sizes
  • Algorithm Comparison: Allows comparison between different algorithms solving the same problem
  • Resource Optimization: Helps in efficient utilization of time and memory resources
  • Scalability Assessment: Determines if an algorithm is suitable for large-scale applications

RAM Model (3 marks)

The Random Access Machine (RAM) model is a theoretical model used for algorithm analysis:

  • Sequential Execution: Instructions are executed one after another
  • Simple Operations: Each simple operation takes constant time O(1)
  • Memory Access: Accessing any memory location takes constant time
  • No Concurrency: Single processor with no parallel operations

Asymptotic Notations (5 marks)

1. Big-O Notation (Upper Bound)

f(n) = O(g(n)) if f(n) ≤ c·g(n) for all n ≥ n₀

Example: f(n) = 3n² + 2n + 1 = O(n²). Represents worst-case time complexity.

2. Big-Ω (Omega) Notation (Lower Bound)

f(n) = Ω(g(n)) if f(n) ≥ c·g(n) for all n ≥ n₀

Example: f(n) = 3n² + 2n + 1 = Ω(n²). Represents best-case time complexity.

3. Big-Θ (Theta) Notation (Tight Bound)

f(n) = Θ(g(n)) if f(n) = O(g(n)) and f(n) = Ω(g(n))

Example: f(n) = 3n² + 2n + 1 = Θ(n²). Represents average-case or exact growth rate.

Question 2: Order Statistics and Worst-Case Linear Time Selection (2+8)

Order Statistics (2 marks)

  • Definition: The ith order statistic is the ith smallest element
  • Minimum: 1st order statistic (i = 1)
  • Maximum: nth order statistic (i = n)
  • Median: Middle element; for odd n: (n+1)/2 th element

Worst-Case Linear Time Selection Algorithm (8 marks)

SELECT(A, p, r, i):
1. Divide n elements into groups of 5
2. Find median of each group by sorting
3. Recursively find median of medians (x)
4. Partition array around x
5. Let k = rank of x
6. If i = k, return x
7. If i < k, recurse in left partition
8. If i > k, recurse in right partition

Time Complexity:

T(n) = T(n/5) + T(7n/10) + O(n) = O(n)

Floyd-Warshall Algorithm (6 marks)

FLOYD-WARSHALL(W):
    n = W.rows
    D⁰ = W
    for k = 1 to n:
        for i = 1 to n:
            for j = 1 to n:
                d[i][j]ᵏ = min(d[i][j]ᵏ⁻¹, d[i][k]ᵏ⁻¹ + d[k][j]ᵏ⁻¹)
    return Dⁿ

Time Complexity: O(n³)

Q4: Binary Search with Divide and Conquer (5)

BINARY-SEARCH(A, low, high, key):
    if low > high: return -1
    mid = (low + high) / 2
    if A[mid] == key: return mid
    else if A[mid] > key:
        return BINARY-SEARCH(A, low, mid-1, key)
    else:
        return BINARY-SEARCH(A, mid+1, high, key)

Time Complexity: O(log n)

Q6: Prefix Code and Huffman Algorithm (5)

Prefix Code: A code where no codeword is a prefix of another (ensures unique decodability).

HUFFMAN(C):
    Q = min priority queue of C
    for i = 1 to n-1:
        z = new node
        z.left = EXTRACT-MIN(Q)
        z.right = EXTRACT-MIN(Q)
        z.freq = z.left.freq + z.right.freq
        INSERT(Q, z)
    return EXTRACT-MIN(Q)

Q7: Insertion Sort (5)

INSERTION-SORT(A):
    for j = 2 to A.length:
        key = A[j]
        i = j - 1
        while i > 0 and A[i] > key:
            A[i+1] = A[i]
            i = i - 1
        A[i+1] = key

Best: O(n) | Worst: O(n²) | Average: O(n²)

Q9: Backtracking (5)

Backtracking systematically tries different decisions until finding a valid solution, undoing choices that lead to dead ends.

N-QUEENS(board, col):
    if col >= N: return true
    for row = 0 to N-1:
        if isSafe(board, row, col):
            board[row][col] = 1
            if SOLVE(board, col+1): return true
            board[row][col] = 0  // Backtrack
    return false

Q11: Complexity Classes P, NP, NP-Complete (5)

  • P: Problems solvable in polynomial time O(n^k). Ex: Sorting, searching
  • NP: Problems whose solutions can be verified in polynomial time. Ex: SAT, Hamiltonian cycle
  • NP-Complete: Hardest problems in NP. Every NP problem reduces to them. Ex: 3-SAT, Vertex Cover

Relationship: P ⊆ NP, NP-Complete ⊆ NP

Q12: Short Notes (2.5+2.5)

a) Tractable and Intractable Problems

  • Tractable: Solvable in polynomial time (P class). Practical for large inputs.
  • Intractable: Require super-polynomial time. Not practical for large inputs.

b) Approximation Algorithms

  • Find near-optimal solutions for NP-hard problems
  • Provide performance guarantee (approximation ratio)
  • Example: Vertex Cover 2-approximation
